# Мастерская мысли

Самостоятельная русскоязычная учебная программа: **36 уроков, 108 проверочных вопросов и 8 интерактивных разборов**. Сайт создан для чтения и практики прежде всего на телефоне.

**Стек:** Vite, native JavaScript (ES modules), семантический HTML5, CSS. Без React/Vue, серверной базы, регистрации и клиентских CDN-зависимостей. Корневая страница тоже собирается Vite.

## Программа

| Направление | Уроки | Практика |
| --- | ---: | --- |
| Аргументация и критическое мышление | 8 | Карта аргумента, вероятности Байеса, логические ошибки |
| Риторика | 8 | Конструктор речи, сравнение рамок подачи фактов |
| Справедливость | 12 | Распределение ресурсов и завеса неведения |
| Деньги и мораль | 8 | Модели рыночных сделок, свободы выбора и общественных норм |

Каждый урок содержит цели, объяснение, разобранный пример, главный вывод, интерактив, самостоятельное задание с подсказками и примером ответа, три вопроса с объяснениями, поле заметок и ссылки на источники. Все уроки открыты сразу. Указанное время — оценка чтения вместе с практикой; это не официальная трудоёмкость курсов Harvard.

Тексты, задания и модели — самостоятельные материалы по направлениям открытых курсов Harvard. Сайт не является продуктом Harvard/edX, полным переводом лекций или сертификационной программой. Публичная доступность чужих материалов не означает разрешения на их копирование; оригиналы доступны по ссылкам.

## Локальный запуск

Нужен Node.js 22.12+; в CI используется Node.js 24.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

`npm test` проверяет состав учебной программы, целостность вопросов, сохранение и восстановление прогресса, защиту импорта, поиск и математические модели. Сборка дополнительно проверяет HTML5 и пути к ресурсам обеих точек входа.

## GitHub Pages

Публикация для репозитория `popovdk/popovdk.github.io`:

- Основной вход: `https://popovdk.github.io/`.
- Дополнительный вход: `https://popovdk.github.io/thinking-school/`.
- Пример прямой ссылки на урок: `https://popovdk.github.io/#/lesson/logic-01`.

Обе страницы — полноценные HTML5-входы Vite, использующие общие модули. Маршрутизация через hash позволяет обновлять прямые ссылки на GitHub Pages без серверного перенаправления. `base: './'` делает ссылки на собранные ресурсы относительными.

Workflow `.github/workflows/deploy.yml` запускается при push в `master`, ручном запуске и pull request. Проверка PR не публикует сайт. Для `master` выполняются `npm ci`, тесты, сборка, загрузка `dist` и деплой через `actions/deploy-pages`. Версии Actions закреплены на SHA.

В **Settings → Pages → Build and deployment → Source** должен быть выбран **GitHub Actions**. Эта настройка относится к репозиторию и не хранится в Git. Для уже существующего Pages её нужно проверить один раз. После этого обычный push в `master` обновляет сайт автоматически. Workflow использует стандартный `GITHUB_TOKEN`; пользовательские токены и секреты не нужны.

## Добавление учебного материала

Курс — объект с метаданными и массивом `lessons`. Стабильный `lesson.id` используется в URL, заметках и прогрессе; не переименовывайте существующие ID без миграции.

```js
interactive: {
  type: 'argument-map',
  title: 'Какая посылка удерживает вывод?',
  prompt: 'Сначала предположите, что изменится без одного основания.',
  reflection: 'Какое допущение нужно проверить в реальной ситуации?'
}
```

Встроенный интерактив монтируется после объяснения и перед самостоятельным заданием. Его состояние сохраняется отдельно для каждого урока. Те же модели можно открыть в лаборатории. Контракт, педагогическая логика и ограничения описаны в [docs/interactive-design.md](docs/interactive-design.md).

## Мобильное использование и доступность

- Одноколоночное чтение, нижняя навигация и закреплённые переходы по частям урока.
- Увеличение текста, видимый фокус, подписи контролов и клавиатурное управление.
- Ползунки дублируются числовыми полями; перетаскивание не требуется.
- Философские оценки сопровождаются текстовым объяснением; смысл не кодируется одним цветом.
- Учитываются `prefers-reduced-motion`, безопасная зона телефона и печать уроков.

## Данные и ограничения

Прогресс, ответы, состояния экспериментов, закладки и заметки хранятся в `localStorage` под ключом `thinking-school.v1`. Они не передаются на сервер и не синхронизируются между устройствами автоматически. В тетради есть JSON-экспорт/импорт и выгрузка заметок в TXT. Импорт заменяет текущую копию после подтверждения. Сброс также требует подтверждения.

Если браузер запретил сохранение или закончилось место, приложение продолжает работать в памяти и сообщает об ограничении. До закрытия страницы скачайте резервную копию. Не используйте приватный режим как единственное место хранения заметок.

Математика вероятностей вычисляется по формуле. Моральные модели условны и не определяют «правильную» позицию. Конструктор речи не использует ИИ и не оценивает смысл свободного текста. Автоматической проверки эссе и чат-бота в этой версии нет.

Источники размещены на странице сайта «О программе и источниках», в каждом уроке и в `docs/sources-*.md`. Материалы Harvard и других авторов сохраняют свои условия использования.
